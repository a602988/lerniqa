# 本機合成測試資料

這個目錄只供 Lerniqa 本機開發、畫面展示與自動測試使用。`database.json` 內的帳號、學習者、學校名稱與作答紀錄都是測試顯示資料，不得視為正式帳號或真實兒童資料。

- 不得把 `runtime-data/`、正式資料庫匯出、使用者上傳檔案或 session 內容複製到這裡。
- 新增資料時使用 `example.com` 信箱、固定測試識別碼與不對應真實個人的顯示名稱。
- 測試若會寫入狀態，應使用獨立暫存目錄或暫存資料庫，不得覆寫本目錄。
- 圖片與題目內容仍需確認授權範圍；「沒有個資」不代表可以任意對外散布。

正式資料搬移必須從受控來源執行，依資料庫設計文件產生舊 ID 對新 UUID 對照、筆數核對與隔離報告，不能直接把這份 fixture 當成 production seed。
