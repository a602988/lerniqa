# Lerniqa｜學睿卡 產品需求規格 v0.1

## 目標
國小至國中學生的個人化練習系統；家長可整理教材、追蹤錯題與考前複習。首版以繁體中文、台灣學制為主。

## 核心角色
- 家長：建立子女檔案、設定年級／科目／段考範圍、匯入題目、查看學習進度。
- 學生：練習、檢視解析、重做錯題。
- 管理員：管理教材與題庫品質（後續）。

## 核心流程
1. 建立學生與年級、學期。
2. 建立考試計畫：學校、科目、第一次／第二次／第三次定期評量、自訂單元、考試日。
3. 拍照／上傳圖片或 PDF；後端 OCR 擷取題幹與選項；由使用者校正。
4. 題目結構化：科目、年級、版本、冊次、單元、知識點、難度、正解、解析、來源。
5. 指派練習；記錄作答日、答案、正確率與耗時。
6. 錯題自動入庫，按知識點聚合；支援重做、熟練度追蹤。
7. 依錯題知識點找出相似題；AI 出題前要做答案驗證與人工可審核流程。
8. 考前儀表板：弱點分布、單元完成率、最近練習與考試倒數。

## 重要資料模型
User, Student, Subject, CurriculumUnit, ExamPlan, SourceDocument, Question, QuestionChoice, QuestionTag, PracticeSession, AnswerAttempt, MistakeReview, GeneratedQuestion。

關聯要求：題目能追溯原始檔案及頁碼；學生作答有時間戳；更正解析不覆寫歷史作答。

## 品質／隱私
- 未成年者資料預設不公開；採最少蒐集。
- OCR 與生成結果不可默默當作已驗證正確答案。
- 影像/PDF 上傳需檔案大小、型態、權限驗證及惡意內容掃描。
- 文件可能涉及教科書著作權：僅允許使用者有權使用的教材，分享功能另設限制。
- 需依臺灣個資法與適用兒少規範設計權限、資料刪除與保存期限。
