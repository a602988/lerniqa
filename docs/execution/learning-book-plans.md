# 學習本計畫交付紀錄

本次在既有 `/practice` 流程內完成「學習本計畫」，沒有建立替代首頁或單科產品，也沒有部署至 Vercel。

## 已完成範圍

- `0017_learning_book_plans` 建立不可變發布版本、版本題目、分享邀請、訂閱、站內通知、稽核事件與冪等收據。
- 學習本可不安排時間，也可建立多筆排程；排程與正式 session 固定引用建立當下的發布版本。
- 學習本、版本、排程與 session 均由 PostgreSQL 保存，不再以 `localStorage` 作為權威資料來源。
- 舊本機資料先顯示搬移預覽，使用者明確確認後才寫入；搬移使用冪等收據，可安全重跑，原始 JSON 備份保留在瀏覽器。無法安全對應的題目或條件會保留待處理，不猜測、不捨棄。
- 列表支援已安排／未安排、本人建立／他人分享、建立者、分享者、同步狀態、狀態、關鍵字及排序篩選。
- 分享網址使用 32-byte 隨機值；資料庫只保存 SHA-256 雜湊。邀請七天到期、一次領取，可由建立者撤銷。
- 分享建立每帳號每小時上限 100 次，邀請檢視／領取合計每帳號每小時上限 300 次；額度以持久稽核事件計算。建立分享的冪等重播不會再次回傳明文 token 或網址，只會標示 token 已在首次回應提供。
- 收件者必須先登入，再選擇自己已有存取權的學習者領取；分享不新增 `learner_access`，也不授予作答成果或其他學習者資料權限。
- 來源發布新版時，仍有效的訂閱自動指向新版；已建立的排程與 session 保持原版本。收件者若要修改內容，必須分叉為自己的學習本。
- 同一題可選多個子題，但必須固定在同一題目修訂版本；正式 session 會合併成一題並只回傳已選子題。同題混用不同修訂版本會回應 `409`，不會寫入 session 或透露題目內容。
- 建立、發布、封存、排程、分享、領取、同步、撤銷、分叉及搬移均留下學習本稽核事件；可操作事件使用冪等鍵防止重送。
- 列表分頁使用不透明的穩定 keyset cursor，保留 PostgreSQL 微秒時間；名稱、建立時間、更新時間與排程時間四種排序皆不以 offset 分頁。排程若已有 active／paused 正式 session，狀態會顯示進行中並拒絕重複開始。

## 持久資料處理

套用 migration 前已建立本機資料庫備份：

`local-data/backups/lerniqa-local-20261017T173410Z`

接著以只向前方式套用 `0017`。沒有執行 seed、reset 或 fixture cleanup，也沒有覆蓋既有題目、帳號、學習者、練習或作答資料。

## 驗證

```bash
npm run test:learning-books
npm run test:learning-books:db
npm run db:test
npm run lint
npm test
npm run build
```

`test:learning-books:db` 使用具隨機名稱的隔離 PostgreSQL 資料庫，涵蓋建立、發布、多排程、授權拒絕、token 只存雜湊、領取與重播、分享排程、分叉、新版同步、舊排程版本固定、撤銷、通知、動態條件搬移、稽核及併發領取。驗證資料庫完成後會清理，不接觸持久資料。

## 尚屬上線工程

本次只完成本機產品流程。production 尚需受限資料庫角色／RLS、公開 rate limit、正式通知 transport、監控、秘密管理與明確授權後的 Vercel 部署。這些不影響目前本機 PostgreSQL 的學習本功能，但完成前不應宣稱 production 已上線。
