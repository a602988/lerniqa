# 草稿清單介面調整計畫

## 範圍

本次只調整 `/questions/new` 的「我的草稿」頁面：草稿清單視覺分組、背景處理狀態，以及刪除草稿的防誤觸流程。後端刪除規則、背景工作生命週期與題目資料契約維持不變。

## 工作包

### 草稿清單視覺分組

- 使用者結果：草稿清單的標題、說明、建立操作與草稿卡片位於同一個白色內容區，不再直接浮在頁面底色上。
- 影響位置：`app/questions/new/question-import.module.css`。
- 修改前重現：開啟「我的草稿」，只有單張草稿卡片是白底。
- 修改後驗證：桌面與窄螢幕檢查清單區白底、邊界、間距及水平溢位。

### 背景工作狀態

- 使用者結果：等待 worker 與 worker 執行中的草稿都以「處理中」呈現；完成與失敗維持各自狀態。
- 影響位置：`app/questions/new/question-import-workspace.tsx`、題目匯入契約測試。
- 修改前重現：草稿卡片顯示「等待分析」或「背景分析中」。
- 修改後驗證：契約測試與瀏覽器 accessibility tree 均可讀到「處理中」。

### 刪除確認視窗

- 使用者結果：按下垃圾桶先開啟具名確認視窗，清楚顯示草稿名稱及不可復原後果；可取消，確認期間顯示「刪除中…」。
- 影響位置：`app/questions/new/question-import-workspace.tsx`、題目匯入契約測試。
- 實作來源：使用專案既有 `@keel-design/ui` Dialog 與 Button，不保留 `window.confirm` 或另建平行浮層。
- 修改前重現：按下垃圾桶開啟瀏覽器原生確認框。
- 修改後驗證：滑鼠與鍵盤操作開啟、取消、Escape、關閉及確認刪除；取消後焦點回到原刪除按鈕。

### 背景分析畫面

- 使用者結果：沒有題目時，草稿名稱與下方題目區在處理中、分析失敗及尚未選擇範本狀態都合併為一個大型白色內容區，不再出現兩張分離卡片或虛線外框；處理中狀態列出頁面校正、文字辨識與題目分析，但不顯示沒有可靠資料來源的百分比進度。
- 影響位置：`app/questions/new/question-import-workspace.tsx`、`app/questions/new/question-import.module.css`、題目匯入契約測試。
- 修改前重現：開啟處理中的草稿，草稿資料下方顯示高度 24 rem 的虛線空白區。
- 修改後驗證：桌面與窄螢幕檢查白色背景、內容密度、狀態語意及水平溢位。

## 回退方式

若驗證出現本輪造成的回歸，只撤回本計畫列出的 TSX、CSS、測試與文件差異，不動其他未提交內容或既有持久資料。

## 完成狀態

- 草稿清單白底內容區：已驗證。
- 「處理中」狀態：已驗證。
- Keel 刪除確認視窗：已驗證；Escape 與取消後焦點返回原刪除按鈕。
- 無題目狀態白色內容區：已驗證；草稿資料與下方題目區在處理中、分析失敗及尚未選擇範本時共用外框，桌面與窄螢幕均無水平溢位。
- 公開 API 與資料格式：無變更。
