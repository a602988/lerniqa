# 首頁儀表板視覺調整計畫

狀態：已驗證

## 目標

首頁採用三區式應用框架。桌面版由左側學習者與導覽、中間練習工作區、右側練習摘要組成；手機版依任務順序改為單欄。版面使用淡水綠背景、白色工作區與薄荷綠主色，搭配少量珊瑚紅狀態提示，在不增加操作步驟的前提下提升親和力與專業感。

## 調整範圍

- 重組首頁版面與主要導覽，不改變學習者、練習、錯題及匯入的資料流程。
- 將練習統計合併為單一資訊區塊，避免用多張獨立卡片切碎內容。
- 把練習摘要與考試日期集中到右側區域，主要操作仍留在練習設定旁。
- 學習總覽的「目前弱點」與「最近練習」同樣歸入桌面右側摘要欄；手機版則收在可展開的「練習摘要」面板，維持完整可讀性。
- 互動控制繼續使用 Keel 元件，色彩、圓角與陰影改由專案語意化樣式統一管理。
- Keel 採用 green skin，專案層再統一主色、焦點色、文字色與狀態色，避免控制元件殘留其他色系。
- 大面積內容色塊使用接近白色的淡灰；薄荷綠只保留在背景、主要操作與小型狀態提示，不重複鋪滿內容區。
- 側欄主色只表示目前選取的功能。「開始練習」未被選取時使用一般導覽樣式；所有選取項目統一使用原「開始練習」的紫色實心狀態。
- 「新增題目」使用帶有文件外框的新增圖示，並沿用其他導覽項目的圖示容器、尺寸與底色。

## 驗證方式

- 執行 lint、production build 與 `git diff --check`。
- 以桌面與 390px 手機寬度驗證學習者切換、主要導覽、設定對話框及開始練習。
- 切換「開始練習」、「學習本計畫」、「學習總覽」、「題目總覽」與設定頁，確認同一時間只有目前項目使用紫色實心選取狀態。
- 部署後開啟正式網址並檢查 console 與 HTTP 狀態。

## 回退方式

若新框架造成操作或響應式回歸，只撤回首頁結構與專案視覺樣式，不修改模擬資料、作答紀錄格式或學習流程。
