# 首頁視覺品質調整計畫

狀態：已驗證

## 目標

保留學習者切換、練習、錯題與匯入流程，改善桌面版內容過度集中、區塊間距不足與主次層級不明顯的問題。完成後，頁首、主要導覽、練習設定與摘要要能分成清楚的閱讀段落，手機版仍維持單欄順序。

## 調整範圍

- 增加頁面、頁首、導覽與主要內容之間的垂直留白。
- 使用 Keel 的 `Tabs`、`Card`、`FormField`、`Button` 等元件，調整既有元件的尺寸、外觀與組合方式。
- 強化主卡片、練習摘要與主要按鈕的層級，不改變資料與操作邏輯。
- 加入低彩度背景與陰影，維持文字對比與控制項辨識度。

## 驗證方式

- 執行 lint、production build 與 `git diff --check`。
- 在桌面與 390px 手機寬度操作學習者切換、分頁與開始練習。
- 檢查瀏覽器 console，並確認正式網址回傳 HTTP 200。
- 驗證完成後部署至 Vercel production。

## 回退方式

若調整造成版面或操作回歸，只撤回本計畫涉及的樣式與 className，不動既有資料模型、模擬資料與學習流程。

## 驗證結果

- lint、production build 與 `git diff --check` 通過。
- 桌面與 390px 手機寬度的版面、學習者切換及主要分頁操作正常。
- 正式站瀏覽器 console 沒有錯誤或警告，`https://lerniqa.vercel.app/` 回傳 HTTP 200。
