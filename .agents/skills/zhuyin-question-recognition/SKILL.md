# 注音題目辨識

先讀 [注音題目圖片辨識規格](../../../docs/bopomofo-question-recognition.md)。實作與審查以 `app/lib/bopomofo-recognition.ts` 的執行規則為準；文件說明產品行為，不得建立另一套平行判斷。

處理圖片中的國字注音題時，逐字保留原稿的前後文字、引號、注音符號及聲調。語境只用來檢查候選，不可補出答案、完整詞語或題目未印出的讀音。

任一符號無法確認時，保留可辨識的前後文字，並在原作答位置建立緊密的 `crop_ref`。替代文字使用「待確認的注音原文」。不要用相似國字、日文假名、拉丁字母或語意推測填補。

修改辨識規則時，新增一個能重現錯誤的契約測試。至少執行：

```bash
npm run test:question-import
npm run lint
```

真實圖片驗證只能使用已獲授權或合成資料。未量測固定資料集前，不得描述為已達市場級辨識效果。
